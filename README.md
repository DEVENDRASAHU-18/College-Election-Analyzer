# College Election Result Analyzer

A simple Python program with a clean, easy-to-use GUI for analyzing college election results.

## Features
- **Eligible & Invalid Votes**: Enter total eligible voters and invalid ballots.
- **Add Candidates**: Enter each candidate's name and votes received.
- **Turnout & Participation**: Calculates voter participation percentage and warns if turnout is under 50%.
- **Rankings**: Displays all candidates sorted by votes with percentage share.
- **Outcome Detection**: Identifies the winner with victory margin, or detects ties.
- **Input Validation**: Ensures valid numbers and prevents total votes from exceeding eligible voters.

## How to Run
Run the program with Python:
```bash
python Election_Analyzer.py
```
*(Uses only Python's built-in `tkinter` library — no external packages needed.)*
